# Void Things (无物) - 核心世界观与开发文档

## 🎯 模组基础信息
- **模组名**: Void Things (无物)
- **模组 ID**: `void_things`
- **包名**: `nothing.xiaofan_delta.void_things`
- **技术栈**: Minecraft 1.20.1 / Forge 47.4.10 / Java 17
- **核心依赖**: Nebula Libs 2.6.10, Registrate
- **灵感来源**: 《Deltarune》 (被遗忘的男人、蛋、黑暗喷泉) 、《Oneshot》 (灯泡/寻光) . 

## 🌌 核心世界观
世界原本处于稳定的法则 (MC) 之下, 但在某个被遗忘的角落, 另一套法则 (Deltarune 的暗世界/代码逻辑) 与主世界发生了**冲撞**. 这种冲撞不仅撕裂了空间, 还留下了一种介于“存在”与“不存在”之间的物质——**虚空 (Void) **. 

被遗忘的男人在缝隙中留下了一颗“蛋”, 这颗蛋是开启一切异变的锚点. 

## 🕒 主线流程 (玩家视角) 

### 第一阶段: 偶遇异常 (The Anomaly) 
1. 玩家在主世界与末地之间穿梭, 有极低概率 (2%) 被拉入纯黑维度 `void_things:strange_place`. 
2. 该维度无尽黑暗, 只有紫方块 (`purple_block`) 铺就的平台、一棵方块树, 以及树后展示架上的一颗**“蛋” (Egg) **. 
3. 取得蛋后, 通过背后发光的传送门返回主世界坐标 `(66, 66, 66)` 的安全屋. 

### 第二阶段: 黑白污染 (The Corruption) 
1. 将“蛋”丢入原版水中, 水被污染为 **`void_things:water`** (视觉呈黑白故障噪点, 文本显示为带删除线的斜体“水”) . 蛋则退化为普通的鸡蛋. 
2. 玩家利用滴水石锥, 将异常水滴滴在铁块/金块上. 
3. 铁块/金块会逐渐被侵蚀 (经历 `stage 0 -> 1 -> 2`) , 最终转化为纯黑方块 (`black_ingot_block`) 和纯白方块 (`white_ingot_block`) . 
4. 利用黑白方块制作组装机, 产出能正常显示“OK”的控制台. 

### 第三阶段: 荒芜遗迹 (The Ruins) 
1. 搭建特定的多方块结构, 传送至 `void_things:ruins` 维度. 
2. 这里是虚空蔓延的尽头, 尽是荒芜. 玩家在此收集“无之碎片”等材料, 开启“无物”系列. 
3. 在这片黑暗中, 玩家会找到 Oneshot 风格的破碎灯泡. 点亮灯泡可以降低 DP (德润指数) . 

### 第四阶段: 终局破局 (The Revelation) 
1. 当“无物”科技发展到一定程度, 玩家携带点亮的光源, 再次进入 `strange_place` 维度. 
2. 此时纯黑世界被照亮, 玩家在树的背后发现隐藏的道路, 获得黑系列的终极物品, 了解被遗忘的真相. 

## 🧠 核心机制设定

### 1. DP (德润指数 / De-rune Point) 
- **概念**: 衡量玩家受异世界法则 (Deltarune) 侵蚀的程度. 
- **获取**: 玩家触碰或浸泡在 `void_things:water` 中时增加. 
- **满值 (100) 惩罚**: 睡觉时无法正常入眠, 会被拉入梦魇维度 `void_things:dark_world`. 

### 2. 梦魇与惊醒 (dark_world) 
- **梦境死亡**: 玩家在梦魇维度死亡不会真死. 会在主世界惊醒, DP 降至 90, 保持当前时间 (未度过黑夜) , 并获得 Debuff **“暗影残响” (`darkness_echo`) **. 
- **黑暗喷泉**: 在梦境中找到黑色的喷泉 (DR 风格) . 右键用红心 (生命值) 共鸣封印. 封印成功后 DP 降至 20, 清除 Debuff, 保留 1 点血和 1 格饱食度醒来. 

### 3. 暗影残响 (darkness_echo) 
- **图标**: 黑白故障线包裹的红心 (致敬 DR) . 
- **效果**: 无法睡觉, 附带轻微移速下降和屏幕扭曲 (反胃) . 
- **解除**: 在主世界 (自然维度) 白天到来时, 自动清除.
